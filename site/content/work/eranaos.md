## Agents in an ongoing world

EranaOS explored a persistent desktop environment in which agents could build relationships, interact with one another, and assist with work. Its launch note placed agent behavior inside a continuing simulated social world.

The project extends a recurring theme in Richard's work: what changes when an AI system is given an environment and continuity rather than only an isolated conversational turn?

## Archived status

Deep SIML now lists EranaOS as archived and states that active development has concluded as the lab focuses on simulation, optimization, and future physical research.

This entry preserves the exploration as part of the engineering history. The original note describes the project's aims at launch; it should not be read as an offer of a currently maintained service.
